# Reporting a security vulnerability

Report suspected vulnerabilities privately to NVIDIA PSIRT, not through a
public GitHub issue or discussion.

- [NVIDIA vulnerability submission](https://www.nvidia.com/object/submit-security-vulnerability.html)
- Email: [psirt@nvidia.com](mailto:psirt@nvidia.com)
- [PGP key](https://www.nvidia.com/en-us/security/pgp-key)
- [PSIRT policies](https://www.nvidia.com/en-us/security/psirt-policies/)

Include the sample version or commit, platform and dependencies, reproduction
steps, a proof of concept if available, and potential impact. Review logs before
sharing; omit credentials and unrelated visitor data.

For ordinary bugs, use the maintainer contact in the README metadata.
No response-time SLA is implied.
