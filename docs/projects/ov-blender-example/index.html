ovrtx Blender Example

Bring NVIDIA RTX rendering into Blender. Keep creating in the workflows you already know, review your scene through ovrtx, and render a final image without moving your work into a separate application.

Status: Working July 2026

This public example for Blender 5.1 packages a Blender add-on that connects your open scene to NVIDIA ovrtx for real-time rendered viewport review and final-frame rendering. When supported SimReady physics properties are present, NVIDIA OVPhysX drives rigid-body motion in the Timeline before you take an asset into a larger Isaac or Omniverse workflow.

It demonstrates focused creative rendering and SimReady prop review workflows on supported NVIDIA RTX workstations. It is not a supported production renderer and does not reproduce every Cycles, EEVEE, or Blender feature.

What you can do

  • View the current Blender scene through ovrtx in the rendered viewport
  • Orbit, pan, and frame your work while the ovrtx image updates
  • Render a final image using the active Blender camera
  • Adjust supported materials, lights, cameras, and object transforms without leaving Blender
  • Play supported SimReady rigid-body motion with OVPhysX in the Blender Timeline

The add-on works with the scene already open in Blender — whether you created it in Blender, opened a .blend file, or imported USD through Blender's normal import workflow.

Prerequisites

  • Blender 5.1
  • A supported 64-bit release platform (see the project Support Platforms doc)
  • A compatible NVIDIA RTX GPU and driver
  • Internet access if installing the runtime from GitHub

Install

  1. From the ov-blender-example project, download ov-blender-example-<platform>.zip and copy the paired Release page URL for an online runtime install, or download all assets for your platform into one directory for a local install.
  2. In Blender, choose Edit → Preferences → Add-ons and install the ZIP with Install from Disk.
  3. Enable ovrtx Blender Example if Blender does not enable it automatically.
  4. For an online install, enable System → Allow Online Access in Blender preferences.
  5. Open the add-on's View Details panel. Paste the paired Release page URL or select the absolute directory containing all downloaded release assets, then choose Install Runtime.
  6. Wait until the panel shows Runtime: ready and Preflight: pass before selecting the render engine.

The runtime installs separately from the Blender add-on. NVIDIA rendering and physics components run outside the Blender process while the add-on provides the Blender experience.

Render your first scene

  1. Open a .blend file or create a scene in Blender.
  2. In Render Properties, set Render Engine to ovrtx Example.
  3. In the 3D Viewport, select Rendered shading.
  4. Use Blender's normal orbit, pan, zoom, camera, selection, and transform controls.
  5. Press F12 to render the active camera.

The first image can take longer while the runtime starts and prepares rendering resources. Later viewport updates reuse the active rendering session.

How it works

Blender remains where you create, edit, and view your scene. The add-on translates the current Blender scene to USD and sends it to the separately installed NVIDIA Library Worker. ovrtx renders the scene and returns pixels to the Blender viewport. When supported physics properties are present, OVPhysX supplies updated poses for ovrtx to render.
