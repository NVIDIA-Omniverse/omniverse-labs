# Marble relay documentation media

Original geometry and procedural texture sources were authored for this example under MIT. No third-party scene or texture downloads were used for the marble relay.

The hero is the eight-second v16 video at 1600 × 900 and 30 fps. A v17 still is also included in the media assets. Camera and physics screenshots are actual Blender captures; the physics panels use build 40 at 150% UI scale.

Capture details and file hashes are recorded in `marble-provenance.json`. The editable scene and its dependencies are not included in this documentation bundle.
