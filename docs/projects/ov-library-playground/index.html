Omniverse Libraries Playground

Explore Omniverse libraries through hands-on examples. Try their features, discover where they fit your use case, and follow the code to build something of your own.

Eight interactive library showcases November 2026

The Playground brings eight libraries into one interactive campus. Walk through a virtual campus, enter a gallery and change the scene with live controls. Watch a robot's sensor views respond to an obstacle, compare how cartons behave under different physics settings, or turn one reusable asset into a fleet.

Each showcase runs the library it demonstrates. Whether you are getting familiar with Omniverse or exploring an idea for an application, you can connect a feature to a concrete result, then open the source to see how it works.

A guide to help you get started

Meet the robot beside the NVIDIA sculpture. Walk up and choose a conversation topic to learn what a library does, what to try in its room and how the example works. Explore on foot, or use the navigation bar to jump directly to another showcase.

ovrtx: see the scene through a robot's sensors

Start with a moving robot and compare a LiDAR point cloud with front- and rear-facing fisheye camera images. Pause the robot, move the target pallet and watch the sensor outputs change. These views make it easy to explore how one scene can supply different kinds of visual and spatial information.

Switch to the concept car or robot arms to explore another side of the renderer: compare surface finishes, adjust lighting and see how materials and reflections respond. The same gallery connects sensor rendering with visual design review.

ovphysx: experiment with motion and contact

Choose a transfer height and release cartons onto a receiving conveyor. The static arrangement on the left provides a reference while rigid-body simulation runs on the right. Change gravity and repeat the drop, settle a stack and nudge its top layer, or compare stopping distances at different friction settings.

These experiments offer an approachable way to understand the effects of physics parameters before applying them to your own handling, robotics or digital-twin scenarios.

ovstage: one shared scene, multiple views

Grow a single mobile robot into a fleet of reusable asset instances. Change their shared cargo and send them across the exhibit, then compare the main view with the second camera. Both reflect the same scene updates.

The example shows scene composition and live updates in a form you can inspect immediately. Fleet motion is scripted; the focus is organizing and updating shared scene data.

Five more libraries to explore

  • ovui: operate a pallet stacker with buttons, sliders and status controls. Compose a panel and see multiple widgets share the same value model.
  • ovstorage: save a scene revision, change the layout and restore an earlier snapshot through the library's local file backend.
  • ovstream: send rendered frames to a local receiving client and commands back to the scene. Pause and resume delivery to explore the connection.
  • ovnewton: compare articulated gantry transfers and see how the motion profile changes a suspended load's sway.
  • ovpackage: publish an asset with its dependencies, install a revision in a receiving workspace, verify the files and restore a modified copy.

From exploring to building

The Playground is also a sample you can study and extend. Each room includes example-code access so you can see how its features are implemented. Use the examples as starting points for your own interfaces, scenes and workflows.
