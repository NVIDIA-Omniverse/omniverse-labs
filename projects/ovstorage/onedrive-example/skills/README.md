# Skills

This directory holds the skills for the OneDrive Storage Service repository.
Skills are self-contained guides — each is a folder with a `SKILL.md` entry point
and supporting `references/` files.

> **Location note:** Skills for this repository live here, under `skills/` at the
> repository root (`/skills`).

## Available skills

| Skill | Description |
|---|---|
| [`onedrive-deployment/`](onedrive-deployment/SKILL.md) | Deploying, configuring, and integrating the service with Kit App Streaming — Entra ID setup, Bearer pass-through vs. On-Behalf-Of (OBO) auth models, Microsoft Graph permissions, end-to-end connectivity validation, and troubleshooting. Also explains the underlying Graph API implementation and the OBO token lifecycle. |
